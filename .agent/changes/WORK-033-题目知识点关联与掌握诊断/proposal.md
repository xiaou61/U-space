# 题目知识点关联与掌握诊断方案

## 要解决的问题

题目现在只有「块得了几分」，没有逐题历史，因此无法回答「这个用户哪个概念不会、该回去补哪一关」。概念、概念图、自评都已经存在，缺的是题目级证据与概率化的掌握度。

## 选择一：题目关联靠什么算

| 方案 | 做法 | 优点 | 代价 |
| --- | --- | --- | --- |
| A 纯人工 | 作者逐题打标 | 最准 | 114 条目、数百道题，人力成本高 |
| B 词面 + 图传播 + 人工确认（**选它**） | 中文 bigram 词面对齐（题干/选项 vs 概念名/摘要）打分，再沿条目已有概念与概念前置边传播加权，产出 top-5 候选，作者确认 | 无新依赖、可解释、冷启动可用 | 同义改写会漏召回，需人工兜底 |
| C 向量检索 | embedding 召回 | 语义召回最好 | 需引入 embedding 供应商；项目已裁「向量检索暂不做」；无法解释为什么召回 |

选 B 的理由：题目总量小、概念只有 14 个，词面 + 图结构足够；每条候选都能显示「命中了哪些词 / 继承自哪个条目」，便于修正。C 留到概念数与题量上来后重开裁决。

## 选择二：掌握度用什么模型

| 方案 | 优点 | 代价 |
| --- | --- | --- |
| A 保留加权平均 | 零改动 | 不随作答序列演化，无法预测下一次 |
| B BKT（**选它**） | 每概念四参数、可解释、样本需求低（十几次作答即可更新）、纯函数可测 | 假设「答对只受该概念影响」，概念交叉时会偏 |
| C IRT / DKT | 表达能力更强 | IRT 需每题约 200 次作答；DKT 需长序列且不可解释 |

BKT 更新式（每个概念独立）：

```text
学习：P(L) ← P(L) + (1 - P(L)) · T
答对：P(L|+ ) = P(L)(1-S) / [P(L)(1-S) + (1-P(L))G]
答错：P(L|-)  = P(L)S     / [P(L)S     + (1-P(L))(1-G)]
```

参数先验：`P0=0.3, T=0.15, S=0.10, G=1/选项数`（单选题按选项数，判断题 0.5）。参数集中在一个纯函数里，将来可替换为 IRT，不影响调用方。

## 选择三：题目难度怎么估

选 **Elo**（`K=24`，初始 1200，题目评分随作答在线更新）。理由：单次作答即可更新、无需拟合、对稀疏数据友好。IRT 2PL 留到单题作答数达到阈值（≥200）后再评估，届时用同一张 `question_difficulty` 表扩列。

## 选择四：诊断怎么给「回去补哪一关」

选 **带衰减的反向前置搜索**，不是全图 PPR：

```text
从失败概念出发，沿 prerequisite 边反向走，深度 ≤3，权重 ×0.5/层；
跳过 mastery ≥ 0.7 的节点；输出「自身 < 0.7 且所有前置 ≥ 0.7」的前沿节点，按衰减权重排序。
```

理由：概念图当前只有 12 条边、深度浅，BFS 足以覆盖；结果能附上完整路径（「索引 ← B+树 ← 数据结构」），可解释性比 PPR 的分数好得多。PPR 留到图变大后作为排序补充。

## 选择五：练习选题

选 **信息增益 + Thompson 采样探索**：在给定概念集合内，按当前掌握概率选择「期望降低不确定性最大」的题（难度接近当前能力），未校准题（attempts < 5）以 20% 概率优先探索。离线模拟验收（AC-006）。

## 风险与缓解

- **概念标注错**会污染整条链路 → 只允许人工确认后生效；候选记录来源与置信度，可批量撤销。
- **BKT 假设过强**（一道题只考一个概念）→ 允许一题多概念，更新时按关联权重分摊证据。
- **冷启动无数据** → 全部输出 unknown，不用群体均值伪装个人结论。
- **内容改动** → 指纹随题干/选项变化，旧统计保留但不再参与新题难度。

## 不选的东西

DKT、向量检索、跨课程组卷、自动关联直接入库、用掌握度卡解锁。
