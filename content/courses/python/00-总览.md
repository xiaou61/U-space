# Python 从零开始

这门课写给**完全没写过代码**的人。不假设你会命令行、不假设你懂英文报错、也不假设你知道什么是"环境"。

## 这门课怎么排

十二课，每课二十分钟左右，顺序是这么来的：

- 前四课只解决**能跑起来**和**会表达**：环境、运算与条件、循环、函数；
- 中间四课解决**数据怎么放**：列表与元组、字典与集合、字符串、文件；
- 后四课解决**程序怎么长大**：异常、类与对象、继承与多态、小项目。

这个顺序不是拍脑袋：Python 官方教程、哈佛 CS50P、赫尔辛基大学 MOOC.fi 三门课的骨架是一致的，差别只在细节。**不要跳过第 1 课直接看后面**——后面所有例子都假设你能把文件跑起来。

## 每课怎么用

- `讲解` 里有一个**能直接运行**的完整例子，先跑一遍再改几个值看变化；
- `动手` 是一个小练习，做完再看下面的解析；
- `检查一下` 是三道题，答对两题以上再往下走；
- `常见误区` 是别人踩过的坑，**先猜自己会不会踩**再读答案。

卡住的时候点右下角的助手，它会先问你想到哪一步了，而不是直接给答案。

## 学完能做什么

写得出"读一个文件、处理里面的数据、把结果写到另一个文件"这样的脚本，也读得懂别人的小项目。**离找工作还远**，但那不是这门课的目标；目标是让你不再怕代码。
