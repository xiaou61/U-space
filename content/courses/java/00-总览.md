# Java 从零开始

这门课写给**完全没写过代码**的人。不假设你会命令行、不假设你懂英文报错、也不假设你知道什么是"编译"。

## 为什么 Java 比 Python 多一道坎

Python 写完直接跑。Java 要先把源码**编译**成字节码，再由 JVM 执行。这道坎不是麻烦，它带来两件事：

- **编译期就能发现一批错误**（类型不对、方法名拼错），不必等到运行；
- **同一份字节码能在任何装了 JVM 的机器上跑**。

代价是起步多两个命令：`javac` 和 `java`。这一课会用最少的步骤把它们讲清楚。

## 这门课怎么排

十二课，顺序与官方教程（dev.java）和赫尔辛基大学 MOOC.fi 的 Java 课一致：

- 前四课：编译运行、运算符与条件、循环与方法、数组与字符串；
- 中间四课：类与封装、static 与值传递、继承与接口、集合与泛型；
- 后四课：异常、文件、测试与构建、小项目与并发入门。

**Java 的门槛比 Python 高**：要到第 5 课（类与对象）之后，你才真正开始能写"像个程序"的东西。这很正常，别在第 3 课就怀疑自己。

## 每课怎么用

- `讲解` 里有一个**能编译能运行**的完整例子，先跑一遍再改几个值；
- `动手` 是一个小练习；
- `检查一下` 三道题，答对两题再往下；
- `常见误区` 是别人踩过的坑。

卡住时点右下角的助手。它会先问你想到哪一步，而不是直接贴答案。

## 学完能做什么

读得懂一个几百行的 Java 类，能自己写命令行小工具，知道 `equals` 和 `==` 的区别、知道泛型擦除意味着什么。**离写 Spring 服务还远**，但那些都是在此之上的事。
